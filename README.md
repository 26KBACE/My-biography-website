📂 public/
This is the main folder containing all the publicly accessible files for the website.

✅ index.html
The main homepage of the biography website.

Likely includes personal details, achievements, experience, etc.

✅ scripts.js
JavaScript file for interactivity (e.g., animations, form handling, dynamic content).

✅ styles.css
Contains the styling and layout rules for the website.

✅ site.webmanifest
Supports Progressive Web App (PWA) capabilities.
Defines things like the app name, icons, and start URL for installability.

📂 docs/
Possibly for documentation or additional markdown/html files.

Might include more personal documents, testimonials, or subpages.

📂 images/
Stores all images used on the website (e.g., profile pictures, banners).

📂 videos/
Stores videos that might be embedded in the biography (e.g., introduction, project demos).

🧾 Summary
This repo contains a static personal website that serves as a digital biography or portfolio. It is intended to showcase:

Personal background and story
Skills and achievements
Media (photos, videos)
Possibly downloadable docs (CV, certificates, etc.)
